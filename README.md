## Run locally

Clone the repository:

```bash
git clone https://github.com/guilhermetxra/newsguard-ai.git
```

Configure your API key:

```properties
openai.api.key=YOUR_API_KEY
```

Run the project:

```bash
mvn spring-boot:run
```

Access:

```text
http://localhost:8080
```
